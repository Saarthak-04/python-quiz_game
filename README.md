# 🎯 Python Quiz Game

An interactive quiz application built using Python and Streamlit. The application fetches random multiple-choice questions from an online trivia API and evaluates the user's answers.

## ✨ Features

- 🎲 Random trivia questions fetched from an API
- 📝 Multiple-choice questions with shuffled options
- ✅ Automatic answer checking
- 🏆 Live score tracking
- 📊 Progress bar
- 📈 Final score and percentage calculation
- 💬 Performance feedback
- 🔄 Option to play again

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- Open Trivia Database API

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Saarthak-04/python-quiz_game
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository's URL.

### 2. Open the project folder

```bash
cd Quiz-Game
```

### 3. Install dependencies

```bash
pip install -r requirement.txt
```

### 4. Run the application

```bash
streamlit run quiz_app.py
```

## 🌐 API

Questions are retrieved from the [Open Trivia Database](https://opentdb.com/).
